.claude/settings.json 설정
Claude Code는 settings.json의 env 값을 읽습니다. macOS/Linux/WSL은 ~/.claude/settings.json, Windows는 %USERPROFILE%\.claude\settings.json 파일을 편집합니다.
아래 JSON을 넣고 <virtual-key>를 발급받은 Anthropic 호환 API 키로 바꿉니다.
ANTHROPIC_MODEL과 ANTHROPIC_SMALL_FAST_MODEL에는 위 모델 테이블의 모델 ID를 그대로 입력합니다.
저장 후 새 터미널에서 claude를 실행하거나 claude --settings ~/.claude/settings.json으로 해당 설정을 지정합니다.

Continue 2.0 Local Config 설정
VS Code에서 Continue 2.0 확장을 설치하고 Continue 사이드바의 Agent 선택기에서 Local Config 톱니바퀴를 엽니다.
Windows는 %USERPROFILE%\.continue\config.yaml, macOS/Linux는 ~/.continue/config.yaml을 편집합니다.
아래 예시처럼 provider는 openai, apiBase는 https://copa.codyssey.kr/v1, apiKey는 발급받은 virtual key로 설정합니다.
model에는 위 모델 테이블의 모델 ID를 그대로 입력합니다. models 아래 항목을 더 추가하면 여러 모델을 등록할 수 있습니다.

name: Codyssey Public API
version: 1.0.0
schema: v1
models:
  - name: Codyssey GPT-5
    provider: openai
    model: gpt-5-mini
    apiBase: https://copa.codyssey.kr/v1
    apiKey: sk-cody-live-md4nTMJtIYLD2PbFeypNLglVGLEBcT_nKedzfGcUfsI
    useResponsesApi: false
    roles:
      - chat
      - edit
      - apply
    capabilities:
      - tool_use
    defaultCompletionOptions:
      maxTokens: 4096

context:
  - provider: file
  - provider: code
  - provider: diff
  - provider: terminal
